เกิดวันที่ 12 สิงหาคม พ.ศ.2552 ชั้นเตรียมอนุบาลศึกษาอยู่ที่โรงเรียนชุมชนวัดท่าซุง,โรงเรียนเทศบาลบ้านปากกะบาด ระดับชั้นอนุบาล1 ถึงชั้นประถมศึกษาปีที่6 ที่โรงเรียนอนุบาลเมืองอุทัยธานี และศึกษาระดับชั้นมัธยมศึกษาปีที่1-ปีที่6 ที่โรงเรียนอุทัยวิทยาคม ปัจจุบันกำลังศึกษาอยู่ที่ชั้นมัธยมศึกษาปีที่5 ชอบกินผัดกระเพราหมูกรอบ งานอดิเรกคือ วาดรูป เต้น
